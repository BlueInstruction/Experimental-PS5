# PX5 shader recompiler — port provenance and adaptation ledger

This directory is vendored code. It is not written by PX5 and must not be
edited casually; every deviation from upstream is listed here.

## Origin

- **Source:** AnyPS5 `core/shader/recompiler/` (BlueInstruction/AnyPS5)
- **Upstream commit:** `262c031692a0ce538707436fa1587b671ace682b` (2026-10-11)
- **License:** GPL-2.0-only — identical to PX5 (`LICENSE` at repo root).
  The upstream license text is preserved as `LICENSE.AnyPS5` in this directory.
- **Scope:** the full recompiler pipeline (RDNA/GFX10.3 decode → IR →
  control-flow structuring → translation → SPIR-V emission → disk cache).

## Why the recompiler is the missing piece

PX5's GPU stack up to M6 transforms guest PM4 packets into committed render
ops (`GnmState` → `GpuOpList`). None of that produces programmable-shader
code: PS5 games ship RDNA shader binaries, and the Adreno/Turnip drivers
underneath PX5 only consume SPIR-V. The vendored recompiler closes exactly
that gap: guest shader bytes in, SPIR-V out. Without it no game pipeline can
ever bind, regardless of how much command processing exists.

## Deviations from upstream (the complete list)

1. `SpirvBackend/src/SpirvOptimizer.cpp` — SPIRV-Tools is not built on
   Android. The file is rewritten as a two-path unit:
   - `PX5_SPIRV_TOOLS` defined (host builds): upstream validate+optimize
     pipeline, byte-for-byte semantics.
   - otherwise: the same Vulkan/SPIR-V target sanity checks implemented with
     SPIRV-Headers only, then the module passes through in the emitter's form.
2. `tests/` dropped — `DummyShaders.cpp` exists only to generate test inputs
   via glslang, which PX5 does not build. Nothing in the library references it.
3. `Deserialize.cpp` dropped — a standalone debug tool with its own `main()`.
4. `CMakeLists.txt` replaced with PX5's static-library definition (upstream's
   file is a `function()` bound to AnyPS5's runtime target and 3rdparty paths).
5. `px5_shim/prx/libc/include/HostThreadLocal.hpp` — upstream's single
   `core/libs` dependency, vendored verbatim (28 lines, POSIX path is plain
   `thread_local`).
6. `generated/ShaderCacheVersion.hpp` — generated by
   `scripts/gen_shader_cache_version.py` (AnyPS5 generates it at configure
   time from a source hash; the semantics — source digest + `APS5_*` switch
   list — are preserved). Committed so the Android build needs no codegen.

## Dependencies

- `app/src/main/cpp/third_party/spirv-headers` — SPIRV-Headers, vendored
  header-only include tree (`include/spirv/unified1`), license alongside.

## Gates

- Host gate: `scripts/shader_recompiler_host/` compiles the whole library on
  g++14/C++20 and runs a synthetic RDNA program through the full pipeline
  (decode → IR → control flow → SPIR-V). Run before every Android CI push
  that touches this tree.
- cppcheck: this directory and `third_party/` are excluded from the PX5
  static-analysis scan (upstream-gated code); the PX5 facade
  (`gpu/shader_pipeline.cpp`) remains inside the scan.

## Update procedure

Re-copy from a newer AnyPS5, re-apply the deviations above (they are all
mechanical), re-run `scripts/gen_shader_cache_version.py`, re-run the host
gate, and update the commit hash here.
